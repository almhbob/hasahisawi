# Hasahisawi Mobile Store Release

This workflow prepares and builds the mobile app for Google Play and iOS.

## 1. Prepare release files

From the repository root:

```bash
node scripts/prepare-mobile-store-release.mjs
```

Current default values:

- Version: `6.5.5`
- Android versionCode: `255`
- iOS buildNumber: `255`
- API: `https://api-server-gilt-ten.vercel.app`

Optional override:

```bash
RELEASE_VERSION=6.5.6 RELEASE_CODE=256 STORE_API_HOST=api-server-gilt-ten.vercel.app node scripts/prepare-mobile-store-release.mjs
```

This script updates:

- `artifacts/hasahisawi/app.json`
- `artifacts/hasahisawi/eas.json`
- `artifacts/hasahisawi/package.json`

It ensures:

- Android APK preview profile is configured.
- Android AAB production profile is configured.
- iOS production profile is configured.
- The app points to the production API.
- Tablet, foldable, and edge-to-edge support remain enabled.

## 2. Run prelaunch checks

```bash
pnpm run prelaunch:check
```

Then:

```bash
cd artifacts/hasahisawi
pnpm run release:check
```

## 3. Build APK for testing

```bash
cd artifacts/hasahisawi
pnpm run release:android:apk
```

This produces an installable Android APK through EAS Build using the `preview` profile.

## 4. Build AAB for Google Play

```bash
cd artifacts/hasahisawi
pnpm run release:android:aab
```

This produces the Android App Bundle required by Google Play using the `production` profile.

## 5. Build iOS for App Store / TestFlight

```bash
cd artifacts/hasahisawi
pnpm run release:ios
```

This uses the `production-ios` profile.

## 6. Build all targets

```bash
cd artifacts/hasahisawi
pnpm run release:all
```

## Required accounts and credentials

The final APK/AAB/iOS artifacts require valid EAS credentials:

- Expo account access.
- Android signing credentials or EAS remote credentials.
- Apple Developer account for iOS builds.
- Valid App Store Connect IDs for iOS submission.

The repository can prepare the release configuration, but the signed binaries are generated by EAS Build.

## Final API smoke test

Before uploading to stores, verify:

```bash
curl https://api-server-gilt-ten.vercel.app/api/readyz
```

The response should report the service as ready and confirm database/Firebase readiness.
