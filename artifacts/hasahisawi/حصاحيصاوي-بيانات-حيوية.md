## 4. طريقة البناء الصحيحة ✅

### الطريقة المضمونة — GitHub Actions:
```
https://github.com/almhbob/hasahisawi/actions/workflows/build-aab.yml
```
1. افتح الرابط أعلاه
2. اضغط **Run workflow** (من الفرع `master`)
3. انتظر ~20 دقيقة
4. حمّل `hasahisawi-vX.X.X-codeXXX-aab` من قسم **Artifacts**
5. ارفعه مباشرة على Google Play Console

### تحديث رقم الإصدار قبل البناء:
```
ملف: artifacts/hasahisawi/app.json
  "version": "5.9.3"          ← غيّر هنا
  "versionCode": 219          ← زِد بمقدار 1
```

### ⚠️ لا تستخدم EAS للبناء النهائي:
- EAS يستخدم مفتاح توقيع مختلف (SHA1: `16:37:ED:...`)
- سيُسبب رفض AAB من Google Play
- EAS مناسب للـ APK التجريبي فقط (preview profile)
- الحد المجاني: بناءان فقط شهرياً (يتجدد أول كل شهر)
